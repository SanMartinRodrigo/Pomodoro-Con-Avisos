# Capturas de pantalla

Agregá imágenes reales de tu aplicación en esta carpeta:

- `inicio.png`: pantalla principal.
- `pomodoro.png`: temporizador Pomodoro.
- `anti-pomodoro.png`: modo de cronómetro libre.
- `estadisticas.png`: panel de análisis.
- `colaborativo.png`: sesión compartida (sin datos personales).

Antes de subirlas, ocultá nombres, mensajes y cualquier dato privado. El README principal incluye enlaces a estas rutas; se mostrarán cuando agregues las imágenes.
